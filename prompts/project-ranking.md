## 🎯 순위 결정 기준

### 1. 바이브 코딩 적합도 (가중치: 35%)
- AI가 코드를 정확하게 생성할 수 있는가?
- 요구사항을 말로 설명하기 쉬운가?
- 생성된 코드의 오류가 적은가?

### 2. 기술 복잡도 (가중치: 25%)
- 연동해야 할 외부 서비스가 적은가?
- 에러 처리가 단순한가?
- 상태 관리가 복잡하지 않은가?

### 3. 테스트 용이성 (가중치: 20%)
- 결과물을 바로 확인할 수 있는가?
- 문제가 생겼을 때 원인 파악이 쉬운가?

### 4. 초기 비용 (가중치: 10%)
- API 비용이 적은가?
- 무료로 MVP 개발이 가능한가?

### 5. 수익화 가능성 (가중치: 10%)
- 완성 후 수익 창출이 가능한가?

## ⚠️ 바이브 코딩 주의사항

### 🔴 반드시 지켜야 할 것

#### 1. 한 번에 하나씩만 요청하기
```
❌ 나쁜 예:
"블로그 자동화 시스템 만들어줘. 글 생성하고, 포스팅하고, 예약 기능도 넣고, 대시보드도 만들어줘"

✅ 좋은 예:
"OpenAI API로 키워드 받아서 블로그 글 생성하는 함수 만들어줘"
→ 완성 후 →
"생성된 글을 티스토리에 포스팅하는 함수 만들어줘"
```

#### 2. 코드 이해 없이 넘어가지 않기
```
❌ 위험한 상황:
AI가 생성한 코드가 작동함 → 이해 안 하고 다음 기능 요청
→ 나중에 에러 발생 → 어디가 문제인지 모름 → 프로젝트 망함

✅ 안전한 방법:
AI가 생성한 코드 → "이 코드가 뭘 하는지 설명해줘" 요청
→ 이해함 → 다음 기능 요청
```

#### 3. 작은 단위로 테스트하기
```
✅ 좋은 흐름:
기능 1개 구현 → 테스트 → 작동 확인 → 커밋
→ 기능 2개 구현 → 테스트 → 작동 확인 → 커밋
→ ...

❌ 나쁜 흐름:
기능 10개 한번에 구현 → 테스트 → 에러 → 어디가 문제?? 😱
```

#### 4. API 키 절대 코드에 직접 넣지 않기
```python
# ❌ 절대 금지
openai.api_key = "sk-xxxxxxxxxxxxx"

# ✅ 환경변수 사용
import os
openai.api_key = os.getenv("OPENAI_API_KEY")
```

#### 5. Git 커밋 자주 하기
```bash
# 기능 하나 완성될 때마다 커밋
git add .
git commit -m "블로그 글 생성 기능 완성"
```
문제 생기면 이전 버전으로 돌아갈 수 있음!

### 🟡 주의할 것

#### 1. AI가 생성한 코드 맹신하지 않기
- AI도 틀릴 수 있음
- 특히 최신 API는 잘못된 정보 줄 수 있음
- 공식 문서 한 번은 확인하기

#### 2. 에러 메시지 그대로 복사해서 물어보기
```
✅ 좋은 질문:
"이런 에러가 나는데 어떻게 해결해?
Error: Request failed with status code 401
at createError (axios.js:16:15)"

❌ 나쁜 질문:
"에러 나는데 왜 그래?"
```

#### 3. 컨텍스트 유지하기
- 긴 대화 중간에 AI가 이전 내용을 잊을 수 있음
- 중요한 결정사항은 문서로 정리해두기
- 새 대화 시작할 때 프로젝트 구조 알려주기

#### 4. 외부 서비스 연동 시 문서 먼저 읽기
```
티스토리 API, 유튜브 API 등은
→ 공식 문서에서 인증 방식 먼저 확인
→ AI에게 "티스토리 API 인증 방식이 OAuth2야" 알려주기
```

### 🟢 꿀팁

#### 1. 프롬프트 템플릿 만들어두기
```
[기능 요청 템플릿]
- 목적: OOO 하는 기능
- 입력: OOO
- 출력: OOO
- 사용할 라이브러리: OOO
- 주의사항: OOO
```

#### 2. 코드 리뷰 요청하기
```
"이 코드에서 보안 문제나 성능 문제 있는지 확인해줘"
"이 코드 더 간단하게 리팩토링할 수 있어?"
```

#### 3. 테스트 코드도 같이 요청하기
```
"이 함수에 대한 테스트 코드도 만들어줘"
```

#### 4. 주석 달아달라고 하기
```
"이 코드에 한국어로 주석 달아줘"
→ 나중에 코드 이해하기 쉬워짐
```

#### 5. 비슷한 기능은 예시 코드 보여주기
```
"이 함수처럼 비슷한 스타일로 OOO 기능 만들어줘"
[기존 코드 붙여넣기]
```

## 🚀 1순위 프로젝트: AI 블로그 자동화

### 바이브 코딩 개발 순서

```
Step 1: 프로젝트 세팅 (Day 1)
├── "Django + React 프로젝트 구조 만들어줘" ✅ (이미 완료!)
├── "OpenAI API 연동하는 설정 만들어줘"
└── ".env 파일로 API 키 관리하게 해줘"

Step 2: 글 생성 기능 (Day 2-3)
├── "키워드 받아서 블로그 글 생성하는 API 만들어줘"
├── "생성된 글 저장하는 모델 만들어줘"
└── "글 생성 테스트해볼 수 있는 화면 만들어줘"

Step 3: 블로그 연동 (Day 4-5)
├── "티스토리 OAuth 인증 연동해줘"
├── "글을 티스토리에 포스팅하는 기능 만들어줘"
└── "포스팅 결과 저장하는 기능 만들어줘"

Step 4: 대시보드 (Day 6-7)
├── "키워드 목록 관리하는 화면 만들어줘"
├── "포스팅 이력 보여주는 화면 만들어줘"
└── "예약 포스팅 기능 만들어줘"
```

### 각 단계별 체크리스트

| 단계 | 완료 기준 | 테스트 방법 |
|------|----------|------------|
| Step 1 | 서버 실행됨 | `./start-dev.sh` |
| Step 2 | 글 생성됨 | API 호출 → 글 반환 확인 |
| Step 3 | 포스팅됨 | 티스토리에서 글 확인 |
| Step 4 | UI 작동 | 브라우저에서 기능 확인 |
