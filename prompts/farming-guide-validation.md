# POE2 파밍 가이드 검증 프롬프트

## 필수 검증 조건
파밍 가이드를 추가하거나 수정할 때 반드시 다음 조건을 충족해야 합니다:

### 1. 리그 확인
- [ ] **현재 리그**: 바알의 운명 (Fate of the Vaal) 리그 기준인가?
- [ ] 이전 리그(Dawn of the Hunt 등) 정보가 아닌가?
- [ ] 리그 메카닉 변경사항이 반영되었는가?

### 2. 게임 버전 확인
- [ ] **POE2** 정보인가? (POE1 아님)
- [ ] POE1에만 있는 컨텐츠가 포함되어 있지 않은가?
  - ❌ 선구자(Harbinger), 상자/매복(Strongbox), 시뮬라크럼, 환영 서판 등
- [ ] POE2에서 실제로 존재하는 아이템/서판인가?

### 3. 출처 검증
- [ ] **출처 URL**이 있는가?
- [ ] 출처가 신뢰할 수 있는 커뮤니티/크리에이터인가?
  - 유튜브 크리에이터 (펍건, etc.)
  - 커뮤니티 사이트 (vortexgaming.io, etc.)
  - 공식 또는 준공식 DB (poe2db.tw)
- [ ] 출처의 작성일이 현재 리그 시즌인가?

### 4. 수익 정보 검증
- [ ] 수익 정보(div/h)의 **근거**가 명확한가?
- [ ] 출처에서 실제로 해당 수익을 언급했는가?
- [ ] 검증되지 않은 추정치가 아닌가?
- [ ] 초기 투자 비용이 현재 시세 기준인가?

### 5. 아이템/서판 검증
- [ ] 추천 아이템이 **poe2scout 시장 데이터**에 존재하는가?
- [ ] 아이템 이름이 정확한가? (영문/한글)
- [ ] 바알 리그에서 사용 불가능한 아이템이 포함되어 있지 않은가?
  - ❌ 액체 탐욕 (Liquid Greed)
  - ❌ 아이템 수량 감독관 (Overseer of Bounty)
  - ❌ 희귀도 감독관 (Overseer of Fortune)
  - ❌ 정제된 탐욕 경로석 (Distilled Greed on Waystone)
  - ❌ 환영 오브/서판 (Delirium Orb/Tablet) - 바알 리그에서 지도에 적용 불가

---

## 검증 실패시 처리
1. **출처 없음**: 파밍 가이드 제거 또는 출처 확보 후 재등록
2. **POE1 정보**: 해당 내용 제거 또는 POE2 정보로 교체
3. **이전 리그 정보**: 현재 리그 기준으로 업데이트 또는 제거
4. **수익 검증 실패**: 수익 정보를 "미정" 또는 "검증 중"으로 표시
