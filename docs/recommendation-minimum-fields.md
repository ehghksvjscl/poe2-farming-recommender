# 추천 데이터 최소 필드 제안

## 목적
MVP 단계에서 “어떤 파밍을 하면 시간당 화폐벌이가 어떤지”, “어떤 준비가 필요한지”, “어떤 빌드가 적합한지”를 설명하기 위한 **최소 필드 집합**을 정의한다.

## 최소 필드
- `zone.league`: 리그/시즌 구분
- `reward.avg_profit_per_hour`: 시간당 수익(평균)
- `reward.drop_focus`: 주요 드랍/보상 유형
- `build.allowed_builds`: 적합 빌드 리스트

## 질문 대응 매핑
### 1) 시간당 화폐벌이
- `reward.avg_profit_per_hour` → 시간당 수익(평균)을 직접 제공

### 2) 어떤 준비가 필요한지
- `zone.league` → 리그/시즌 구분으로 콘텐츠 접근 및 준비 요건 판단

### 3) 어떤 빌드가 적합한지
- `build.allowed_builds` → 적합 빌드 리스트로 빌드 매칭

### 4) 어떤 파밍인지/보상 유형
- `reward.drop_focus` → 주요 드랍/보상 유형으로 파밍 성격 설명

## 결론
위 4개 필드만으로도 MVP 추천 질문(수익/준비/빌드/보상)을 최소 비용으로 커버할 수 있다.
