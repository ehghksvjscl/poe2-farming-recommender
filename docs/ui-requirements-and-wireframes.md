# UI 최소 요구사항 및 와이어프레임

본 문서는 추천 결과 탐색, 필터링, 비교를 중심으로 한 MVP 수준의 UI 요구사항과 초기 화면 와이어프레임, 보조 CLI 범위를 정의한다.

## 제품 목표 기준 최소 UI 요구사항

### 1) 추천 결과 탐색
- **결과 리스트/카드 뷰**: 추천 결과를 카드 또는 테이블로 목록화.
- **핵심 지표 노출**: 시간당 수익, 경험치, 난이도, 콘텐츠 유형 등 최소 3~5개 핵심 지표 표기.
- **추천 사유 요약**: 입력 조건과의 매칭 요약을 1~2줄로 표시.
- **정렬 옵션**: 수익/경험치/난이도 등 기준으로 정렬.
- **페이지네이션 또는 무한 스크롤**: 결과가 많은 경우 탐색성 확보.

### 2) 필터링
- **기본 필터**: 콘텐츠 유형(맵핑/보스/델브 등), 난이도, 시간당 수익 목표.
- **고급 필터**: 빌드 유형, 장비 수준, 플레이 가능 시간.
- **필터 상태 표시**: 적용된 필터를 태그로 표시하고 개별 해제 가능.
- **필터 초기화**: 모든 필터를 한 번에 리셋하는 버튼 제공.

### 3) 비교
- **비교 슬롯**: 2~3개 결과를 선택하여 비교.
- **비교 요약 테이블**: 핵심 지표를 행으로, 추천 항목을 열로 비교.
- **차이 강조**: 상/하위 값 강조 표시.

### 4) 입력/설정 경험
- **입력 흐름**: 홈 화면에서 입력 후 추천 결과 화면으로 이동.
- **입력 데이터 유효성**: 필수 입력 누락 시 안내 메시지.
- **상태 복원**: 새로고침 또는 뒤로 가기 시 최근 입력/필터 상태 유지.

### 5) 접근성/가시성
- **명확한 시각 구분**: 입력 영역, 결과 영역, 비교 영역 명확히 구분.
- **데스크톱 우선 레이아웃**: 데스크톱 화면에서 입력/결과/비교 흐름이 명확하게 보이도록 구성.

## 보조 CLI 범위

CLI는 운영/데이터 관리에 한정하며, 사용자 추천 플로우는 웹 UI로 제공한다.

### 포함 범위
- **데이터 업데이트**: 최신 패치/리그 데이터 가져오기 및 인덱싱
  - 예: `cli update-data --source=community`
- **캐시 초기화**: 추천 캐시 및 파생 데이터 삭제
  - 예: `cli clear-cache --all`
- **데이터 진단**: 데이터 적재 상태/결측치 리포트 출력
  - 예: `cli data-health`

### 제외 범위
- 추천 실행/탐색은 CLI에서 제공하지 않음(웹 UI 전용).
- 사용자 입력 폼 대체 기능 제공하지 않음.
